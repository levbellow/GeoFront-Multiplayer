# GeoFront Multiplayer

Это версия GeoFront с комнатами и синхронизацией карты через WebSocket.

## Запуск на компьютере

Требуется Node.js 18+.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

Для игры с другом сервер нужно разместить на сервере/хостинге, доступном обоим игрокам. HTTPS-сайт должен использовать WSS; сервер уже работает через тот же HTTP(S)-origin, поэтому на обычном HTTPS reverse proxy достаточно прокинуть WebSocket.

## Как играть

1. Откройте «Мультиплеер».
2. Нажмите «Создать» — появится код комнаты.
3. Отправьте другу ссылку вида `https://ВАШ-САЙТ/?room=ABCDE` или сам код.
4. Второй игрок вводит код и нажимает «Войти в комнату».
5. Захваты и Undo/Redo синхронизируются между браузерами.

## Важно

Сервер хранит состояние комнаты в памяти. После перезапуска сервера комнаты исчезают. Для постоянных аккаунтов/сохранений можно позже добавить БД.
